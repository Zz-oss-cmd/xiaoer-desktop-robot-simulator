# TCP虚拟设备联调

该功能使用Python标准库把机器人二进制协议放到真实TCP字节流中运行，不需要开发板。

## 一键演示

1. 双击 `run_virtual_device.bat`，看到 `127.0.0.1:8765` 启动成功。
2. 保持服务端窗口打开，双击 `run_tcp_demo.bat`。
3. 客户端将发送心跳、传感器和巡逻控制三帧，并显示三帧设备状态响应。
4. 服务端窗口同步显示任务入队、状态切换等控制器日志。
5. 在服务端窗口按 `Ctrl+C` 安全停止。

## 展示的工程能力

- TCP只提供连续字节流，协议解析器负责处理拆包和粘包。
- CRC错误帧不会进入控制器，解析器会重新同步后续合法帧。
- 每个有效请求都返回带序号的设备状态帧。
- 客户端断开时更新通信状态，再次发送心跳后恢复。
- 多客户端线程通过互斥锁安全访问共享控制器。
- 网络层、协议层、业务网关和控制器保持分层，可分别测试。

## 命令行

```bash
python virtual_device.py --host 127.0.0.1 --port 8765
python tcp_demo_client.py --host 127.0.0.1 --port 8765
```
