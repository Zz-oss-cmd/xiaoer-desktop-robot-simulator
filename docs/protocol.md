# 小二机器人二进制通信协议 v1

## 1. 设计目标

协议层模拟 UART DMA 每次产生任意长度数据块的情况，解析器不得假设一次接收就是
一帧。它必须在拆包、粘包、随机噪声和错误帧之后恢复同步，并且不依赖 GUI。

## 2. 帧格式

| 字段 | 字节数 | 说明 |
|---|---:|---|
| Header | 2 | 固定 `AA 55` |
| Version | 1 | 当前为 `01` |
| Command | 1 | 命令类型 |
| Sequence | 1 | `0..255`循环 |
| PayloadLength | 2 | 小端序，最大128 |
| Payload | 0..128 | 命令数据 |
| CRC16 | 2 | CRC16-Modbus，小端序 |

CRC范围为`Version`至`Payload`，不包含帧头和CRC字段。

## 3. 命令

| 命令 | 值 | 方向 | Payload |
|---|---:|---|---|
| HEARTBEAT | `01` | 上位机到机器人 | 空 |
| SENSOR_DATA | `10` | 上位机到机器人 | `<HHhH>` |
| CONTROL | `20` | 上位机到机器人 | 动作，可选优先级 |
| DEVICE_STATUS | `30` | 机器人到上位机 | `<BHhB>` |

传感器数据依次为距离、电量、温度和光照，均使用0.1单位；温度为有符号数。
设备状态依次为状态编号、电量、温度和任务队列长度。

## 4. 控制动作

| 动作 | 值 |
|---|---:|
| 打招呼 | 1 |
| 巡逻 | 2 |
| 跳舞 | 3 |
| 休息 | 4 |
| 讲笑话 | 5 |
| 显示状态 | 6 |
| 故障恢复 | 7 |

第二个可选字节为任务优先级：紧急0、高1、普通2、低3。

## 5. 边界与恢复

- 最大Payload：128字节
- 最大流缓冲：512字节
- 半帧绝对超时：100 ms，从候选帧开始而不是从最后一个字节重新计时
- CRC或长度错误：丢弃当前候选起点，继续搜索下一帧头
- 未知版本或命令：完整消费该帧并计数，不交给控制器
- 重复命令序号：网关拒绝再次执行，避免控制任务重复入队
- 传感器范围：距离0..5000.0 cm、电量0..100.0%、温度-40.0..125.0°C、光照0..100.0%

## 6. 验证

协议测试覆盖逐字节拆包、多帧粘包、Payload内伪帧头、噪声、CRC错误、非法长度、
版本/命令过滤、绝对超时、缓冲上限和10000帧确定性随机分块压力测试。
